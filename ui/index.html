Discord / Game Setup
1. Select CABLE Input as VC Output above
2. In Discord → Voice → Input Device, select CABLE Output
3. To mix your mic: Control Panel → Sound → Recording → right-click mic → Properties → Listen → check Listen to this device → playback to CABLE Input
⚠ Each app needs its mic input set to CABLE Output individually — or set it as your Windows default recording device to cover all apps at once.
